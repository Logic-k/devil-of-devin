## 실전에서 잡은 버그
1. 게이트 러너가 bare `bash`를 띄우면 WSL 런처가 잡혀 `C:/…` 스크립트를 못 찾음(exit 127) → Git for Windows bash 탐색(`git_bash()`), 스크립트는 `.devil/tmp/`에 생성.
2. 구현 워커가 "정본" 경로를 알자 게이트 정의를 고쳐 master에 직접 커밋함 → 프롬프트에 읽기 전용·수정 금지 명시 + 통합 전 보호 경로 diff 검사로 거부.
3. 중단 후 태스크가 `in_progress`로 남음 → pending 복구.
4. 문서 탭 자동 열기(window 이벤트)가 마운트 타이밍에 유실 → store `pendingDoc` 으로 교체.

- 커밋하지 않음 (작업 트리에 전체 변경 있음).
- 스크래치 프로젝트 `D:\dod-looptest` 와 설정의 프로젝트 목록(Devil_of_Devin, dod-looptest)은 그대로 둠.
